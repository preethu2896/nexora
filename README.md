# Nexora

A modular AI system workspace featuring RAG retrieval, Model Context Protocol (MCP) tool integration, and hierarchical multi-agent orchestration powered by Google Gemini and LangGraph.

## Repository Overview

- **[Project 1: RAG System (`project-1-rag`)](./project-1-rag)**
  - Document ingestion, chunking, and ChromaDB vector retrieval using Google Gemini embeddings and LLMs.
- **[Project 2: MCP Integration (`project-2-mcp`)](./project-2-mcp)**
  - FastMCP tool server and client graph executing arithmetic and text processing functions.
- **[Project 3: Multi-Agent Supervisor (`project-3-agent`)](./project-3-agent)**
  - LangGraph hierarchical multi-agent workflow coordinating RAG search and MCP tools via intelligent routing and supervisor agents.

## Getting Started

Refer to the individual project directories for detailed setup instructions, environment variable configurations (`.env.example`), and test suites.
